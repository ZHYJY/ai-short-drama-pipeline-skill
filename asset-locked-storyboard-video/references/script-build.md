# 阶段 ① 剧本结构化

## 目标

把用户给的一段剧情（可能只有一句话、一个梗或一段对白）变成能直接进入分镜的剧本包。产出必须能让下游"照着写字就能画图"。

## 1. 角色卡

每角色 8 个字段，全部写死，后续原样复制：

| 字段 | 写法要求 | 例 |
|---|---|---|
| 年龄气质 | 数字年龄 + 一句话气质 | 23 岁，中国女大学生，松弛但心虚 |
| 脸型五官 | 脸型 + 眼睛 + 特征 | 鹅蛋脸、单眼皮、皮肤偏白 |
| 发型 | 长度 + 走向 + 细节 | 黑长直及肩，一侧别到耳后 |
| 上衣 | 版型 + 颜色 + 图案 | 浅灰连帽卫衣，胸前褪色旧印花 |
| 下装 | 版型 + 颜色 | 深灰工装裤，裤脚微堆 |
| 鞋 | 类型 + 颜色 | 白色运动鞋 |
| 随身物 | 1–3 件，且剧情会用到 | 白色头戴耳机挂脖、左腕黑色手环 |
| 标志细节 | 一眼能认出这个人的点 | 说话时习惯摸耳机 |

避坑：
- 不要写"帅""漂亮""气质好"这类无法落图的词。
- 不要给 AI 一眼画不出的小配饰，比如"锁骨上很小的痣"。
- 随身物要克制：超过 3 件，模型就会自己加东西。

## 2. 场景卡

5 项以内：地点 / 时间 / 光位 / 关键陈设（3–5 件）/ 色调。

例：
- 地点：高校教研室，靠窗深色木桌
- 时间：午后
- 光位：右侧窗户斜射自然光，空气中有细小灰尘
- 陈设：几叠打印论文、两本厚书、靠墙白色书架
- 色调：低饱和青灰，写实电影感

全片场景越多，一致性越差。优先 1 个主场景；第二场景只能是同一世界观下的近邻空间（同一栋楼的走廊）。

## 3. 道具卡

只列**剧情必须出现、而且会被镜头拍到**的实物。每件写：名称 / 材质 / 状态 / 出现在哪一段。

- 打印论文：A4 纸，一叠约 30 页，边缘有折角，段01–04
- 深蓝文件夹：硬壳，A4 大小，段05
- 手机：黑色，屏幕朝下，段03

特写里有文字的道具一律标注"纸面文字模糊不可读"。

## 4. 剧情分段表

| 段 | 时长 | 信息任务（这段要让观众知道什么） | 场景 | 出场人 |
|---|---|---|---|---|
| 段01 | 15" | 学生交稿并自称自己写的 | 教研室 | 学生、导师 |
| 段02 | 15" | 导师追问模型，学生露馅 | 教研室 | 两人 |

规则：
- 每段只完成**一个新信息**。两段说同一件事 → 合并或删掉。
- 第一段必须在 5 秒内建立"谁、在哪、要干什么"。
- 最后一段必须给一句能被截图转发的收尾金句。
- 段数 = 目标总时长 ÷ 单段时长，向下取整。

## 5. 对白

- 中文口语，短句为主，每句 8–18 字。
- **字数预算：每秒约 5 字，15 秒段上限约 65 字（含标点停顿只剩 55 字左右，所以要留余量）**。超字数的直接砍，不要指望模型念快。
- 每段 3–4 句，且必须构成一个回合：问 → 挡 → 逼 → 露。
- 冲突要落在台词里，不要靠旁白解释。

## 6. 交付格式

```markdown
# 《片名》

## 一句话梗概
## 主题句（结尾金句）
## 角色卡
### 角色A …
### 角色B …
## 场景卡
## 道具卡
## 分段表
## 逐段对白
### 段01
1. 学生：……
2. 导师：……
```

剧本确认后才进阶段 ②。用户一句"可以"即视为确认。


## v2补充
先执行平台能力预检；台词按可说话秒数和实测语速预算。总时长除不尽时保留尾段，不再直接向下取整丢弃剧情。用户只要求某一阶段时不强制等待全流程确认。
