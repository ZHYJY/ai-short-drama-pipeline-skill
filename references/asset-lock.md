# 阶段 ③ 资产锁定与首帧

## 为什么必须锁

视频模型每段单独生成，段与段之间没有任何记忆。人物、场景、道具的一致性全靠**你喂给它的图**。喂图不足，就会出现：第二段换脸、第三段换外套、第四段桌面凭空多出东西。

## 三类资产生成

### 1. 角色四视图

标准形态：白底，横向 4 栏，同一光线、同一比例、同一套服装。

| 栏 | 内容 |
|---|---|
| 1 | 正面全身（站直，双手自然下垂） |
| 2 | 侧面全身（90°，朝右） |
| 3 | 背面全身 |
| 4 | 头部近景（正面，表情中性） |

提示词模板：

> 角色设定四视图，白底，横向四栏等分：正面全身站姿、右侧面全身、背面全身、正面头部近景。人物为<角色卡全部 8 项原样复制>。同一柔和正面光，无投影，无背景元素，服装与配饰四栏完全一致，表情中性，写实摄影质感。

注意：
- 四栏的服装描述只能出现一次（在开头统一写），不要在每栏重复描述，否则模型会给四栏穿不同衣服。
- 不要写"微笑""看向镜头"等会破坏中性的词，头部近景要中性便于当参考。

### 2. 用户已上传角色图时

**不要重绘。** 用户上传的那张就是他认的形象，重绘必然"改脸"。
- 直接把它作为该角色的唯一参考图。
- 如果它是一张拼版四视图，且下游模型只吃单张图：从最清晰的那一栏（通常是头部近景或正面全身）裁出一个版本作为主参考。
- 如果下游模型要求输出比例跟随输入图（例如某些图生视频接口），另裁一个 9:16 白底居中版本备用。
- 原图很大（>5MB）时先压缩或裁切，避免读取失败。

### 3. 场景板

一张空镜，不含人物：

> 空场景参考图：<场景卡 5 项原样复制>。无人物，无文字，竖版 9:16，写实摄影质感，光线方向明确，陈设位置清晰。

场景板的作用是让每段的首帧共享同一个空间。**同一场景只做一张，全片复用。**

### 4. 道具板

只拍物件，不带人：

> 道具参考图：<名称、材质、状态>，正面 45° 俯视，浅灰或白底，写实摄影质感，画面无文字。

剧情里被"点住""翻开""推到桌边"的道具必须单独出板，否则每段长得都不一样。

## 首帧合成

每段一张，输入 = 该段涉及的角色图 + 场景板 + 关键道具图 + 第 1 镜描述。

提示词模板：

> 竖版 9:16 电影感画面，写实摄影质感。<场景描述>。<角色A 卡描述原样>，<角色B 卡描述原样>。人物关系与站位：<谁在前景谁在后景，左/右>。镜头：<景别>，<角度>。光线：<场景卡光位>。桌面/手边有<道具>。画面内不出现任何文字。

要求：
- 首帧必须**已经呈现第 1 镜的构图**，不要画一个"通用画面"再指望视频自己运镜过去。
- 人物数量、服装、道具在首帧里错一个，整段都会错。

## 首帧与资产质检清单

逐张过，任何一项不过就重做该张：

- [ ] 脸：与角色参考是否同一张脸（眼型、鼻型、脸型轮廓）
- [ ] 发型：长度、分缝、别耳后的那一侧是否一致
- [ ] 服装：上衣颜色版型、下装、鞋，是否与角色卡文字一致
- [ ] 配饰：耳机、手环、眼镜等是否**该有的有、不该有的没有**
- [ ] 左右关系：与全片轴线是否一致
- [ ] 光位：光从哪边来，阴影落在哪边，是否与场景板一致
- [ ] 道具：该出现的出现，不该出现的没有
- [ ] 构图：是否留出了台词镜头需要的空间（近景要留头顶余量）
- [ ] 文字：画面里没有任何可读文字

## 常见失败

| 现象 | 原因 | 处理 |
|---|---|---|
| 四视图四栏穿不同衣服 | 每栏重复描述了服装 | 服装只在开头说一次 |
| 四视图被模型理解成"四个人" | 单图多人物构图 | 追加裁一张单人正面图作主参考 |
| 首帧脸像但气质不对 | 只给了脸没给神态 | 加一句"表情<具体情绪>"，别写"自然" |
| 首帧凭空加人/加物 | 描述里出现"旁边""身后"等模糊词 | 删掉所有未明确指认的人物与物件 |
| 每段首帧桌面陈设都不一样 | 没给场景板 | 必须挂场景板 |


## v2补充
四视图是可选身份资产，不是所有平台的强制输入；上传原图不覆盖，允许另存裁切副本。资产身份固定，动作/姿势/道具位置按 `continuity-ledger.md` 更新。参考图超限时按平台能力降级。
