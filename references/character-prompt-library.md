# 角色提示词结构与示例
## 通用主提示词模板
【角色身份】CHAR_001 v1，引用已验收主参考图REF_001；不可变锚点：{5-8个经确认特征}。
【身体】{相对身高/头身比/肩臀比/体态}；未知不填。
【当前造型】OUTFIT_001 v1，{颜色、材质、版型、细节、配饰左右}。
【当前状态】{场景、位置、情绪、持物手、起始姿势}。
【镜头动作】{单一可执行主动作、镜头运动、结束状态}。
【视觉约束】保持角色身份锚点及服装版本；允许表情、姿态和走位随镜头变化；不得把其他角色的特征赋给本角色。
【参考】{平台实际允许的参考资产ID列表}。
【能力相关参数】仅写已验证支持的字段。
## 侧脸镜头
引用已验收侧脸图；若只有正脸，侧脸结构标推定，优先降低转头幅度或先补侧脸基准。
## 多人同框
CHAR_001 位于画面左前景，引用REF_001；CHAR_002 位于右后景，引用REF_002；两人身份、发型、服装、台词严格分别绑定。位置随镜头可变，但必须更新镜头绑定表。
## 负面约束
“不要换脸/不要变装/不要增加人物”只是辅助，不可替代清晰参考与质检；不使用冗长互相冲突的否定词堆砌。
