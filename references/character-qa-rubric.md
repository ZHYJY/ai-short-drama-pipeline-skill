# 角色一致性质检：人工评分+阻断条件
检查范围：主参考 vs 新镜首帧、镜头关键帧、跨段首尾帧；仅文本/提示词无法证明视频一致。
逐项评分0–2：0明显不符，1轻微偏差/无法完全确认，2符合。
A脸部轮廓与骨相；B眼眉形态与相对位置；C鼻唇与独特标记；D发际线和发型；E身体比例；F服装/配饰版本；G场景内人物ID与位置对应；H道具归属；I声音身份（有音频时）；J跨镜状态接续。
每项必须记录可见性，遮挡/未入镜标NA，不能默认2分。
P0阻断：换脸、关键痣消失/移位、眼鼻骨相明显变形、不同角色特征互换、人物数量错、身体比例剧烈改变。
P1阻断或返工：无剧情事件的服装/发型改变、道具突然换手或消失、声音错配、动作起止状态断裂。
推荐门槛：所有可见P0项必须2分，其他适用项平均≥1.7；该阈值是项目建议，不是模型能力保证。评分由可见产物人工复核，自动脚本只检查结构字段。
记录：shot_id, compared_asset, visible_checks, score, severity, evidence, decision, fix_action, reviewer。
失败时先局部修复，不因轻微正常光照差异误判为换脸。
