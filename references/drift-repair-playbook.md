# 角色漂移故障树与修复
A 换脸/骨相变形：核对角色ID与基准参考→换成清晰同角度参考→精简冲突描述→降低转头/遮挡→拆镜；阻断P0。
B 发型/服装漂移：核对outfit_version及发型版本→锁定可见的版型/颜色/左右细节→修正首帧→重生成该镜。
C 多人串脸/串衣：检查每人独立参考及画面位置→降低同框复杂度→改反打/单人镜→必要时分层合成。
D 道具/姿态断裂：对照entry/exit状态→补动作过渡→重做相邻受影响镜头，避免无理由跳变。
E 清晰度/曝光异常：先调整输入尺寸、压缩、光照、镜头运动，再进行身份判断。
F 台词/口型问题：检查平台是否支持原生音频，必要时拆分后期配音/口型处理。
每次只改变一个主要变量，记录before/after、成本、审核证据。单镜最多2次同策略定向修复；仍失败则停止并切换生成策略或提交人工。
不要绕过平台内容审核。不要用任意相似度阈值代替身份审查。
