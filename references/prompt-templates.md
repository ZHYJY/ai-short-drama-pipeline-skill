# 阶段 ③④ 提示词模板

## 视频提示词通用结构（六段式）

按顺序写，缺段就会飘：

```
1 资产锁句（固定，一字不改）
2 画幅与影调
3 场景与光位
4 逐镜描述（镜号 + 秒数 + 景别 + 角度 + 动作 + 台词）
5 声音要求
6 负面约束
```

### 1 资产锁句（模板，原样使用）

> 以首帧画面为第 1 镜开始，严格保持首帧中人物的长相、发型、服装、坐站位置、桌面陈设、窗光方向与色调不变，只改变动作、表情和机位。

### 2 画幅与影调

> 竖屏 9:16，写实电影感，低饱和青灰调，轻微手持感。

（影调按项目定，但全片只用一句，不要每段换词）

### 3 场景与光位

> 同一间教研室，靠窗深色木桌，桌面几叠打印论文，右侧窗户斜射自然光，空气中有细小灰尘。

### 4 逐镜描述

```
第 1 镜（约 0–4 秒）：<景别>，<角度>，<人物><动作>：「<台词>」
第 2 镜（约 4–9 秒）：硬切<景别>，<角度>，<人物><动作>：「<台词>」
第 3 镜（约 9–14 秒）：硬切<景别>，<角度>，<人物><动作>：「<台词>」
```

- 每镜必须写明**景别 + 角度**，这是硬切衔接的唯一依据。
- 台词用中文引号「」包住，模型识别台词比识别叙述更稳。
- 只写"一个动作 + 一句话"，不要在一个镜头里塞两个动作。

### 5 声音要求

> 中文普通话对白，口型与台词同步，保留室内轻微环境声，无背景音乐。

### 6 负面约束

> 画面内不出现任何文字、字幕、水印；涉及纸张、屏幕时，文字模糊不可读。

## 完整示例（15 秒一段）

> 以首帧画面为第 1 镜开始，严格保持首帧中人物的长相、发型、服装、坐站位置、桌面陈设、窗光方向与色调不变，只改变动作、表情和机位。竖屏 9:16，写实电影感，低饱和青灰调。同一间教研室，右侧窗户斜射自然光。第 1 镜（约 0–4 秒）：中景，侧机位平视，女学生抱着论文走进来往桌上一放，笑着说：「老师，写完了，全文我自己写的。」第 2 镜（约 4–9 秒）：硬切过肩近景，从她右后方越肩，后脑与耳机虚化在左前景，导师翻了两页纸后抬眼：「第三章，你用的什么模型？」第 3 镜（约 9–14 秒）：硬切正面近景，她的笑容僵住，右手摸了一下脖子上的耳机，眼神躲开：「……就，主流的那个。」中文普通话对白，口型与台词同步，保留室内轻微环境声，无背景音乐，画面内不出现任何文字、字幕、水印，纸面文字模糊不可读。

## 参考图提交规则

| 图 | 作用 | 缺了会怎样 |
|---|---|---|
| 首帧图 | 构图、光位、人物位置的唯一基准 | 每段构图全变 |
| 角色四视图（每角色一张） | 锁脸、锁发型、锁服装 | 换脸、换衣服 |
| 场景板 | 锁空间、锁陈设、锁光 | 桌面物件乱变 |
| 道具板 | 锁关键实物 | 论文/手机每段长得不同 |

提交顺序：**首帧在最前**（多数平台以第一张为构图基准）。若平台按位置引用，在提示词里显式指代："图1 为首帧，图2 为女学生，图3 为男导师，图4 为道具，图5 为场景"。

平台只支持单张参考图时：只传首帧，把角色卡、场景卡文字**完整写进提示词**，并保留资产锁句。

## 节点参数

| 参数 | 值 |
|---|---|
| 模式 | 图生视频 |
| 比例 | 9:16 |
| 时长 | 15 秒（按平台档位；若只支持 10/14 秒，阶段 ② 就要按该档位压台词） |
| 条数 | 1 |
| 字幕 | 不烧 |
| 音乐 | 不加 |

## 每段提交后立刻做的 5 项验收

1. 时长是否等于目标档位（±0.5 秒可接受）
2. 分辨率是否为 9:16 竖版（常见坑：某段变成 4K 或横版）
3. 人物是否与首帧同一张脸、同一套衣
4. 台词是否一句不漏、有无被吞或被改
5. 画面内是否冒出了文字、水印、字幕

任一项不过：只重做该段，改一处再提交，不要整片重跑。


## v2补充
资产锁句应解释为锁定人物身份、服装、空间、光线与镜头起始状态；角色按分镜可移动。原示例镜头0–14秒需补齐到目标时长。单次多镜仅在平台支持时使用，否则逐镜生成再剪辑。影调不是必须青灰色，遵循项目设定。
