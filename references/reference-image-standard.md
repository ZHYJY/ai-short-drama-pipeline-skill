# 角色参考资产生产与验收
推荐资产（按预算渐进）：A主身份正面半身清晰图；B全身正面；C左侧脸；D右侧脸；E三分之四角度；F背面；G标准表情表；H服装细节；I手部与标志性道具。不是所有平台都要一次输入全部图片。
统一规范：尽量同一造型版本、中性表情、可比光照、无强滤镜、无遮挡脸、明确画幅与人物占比；侧脸不能简单镜像替代另一侧，尤其有不对称痣/发缝时。
多视图拼版要标注各视角、同一角色ID和版本；若平台可能误把拼版当多人，优先使用单图/逐镜参考。参考图过多不等于更稳定。
原图证据优先级：用户确认参考 > 用户指定文字 > 经人工验收的派生视角 > 自动生成候选。推测不可当事实。
表情表：中性、微笑、愤怒、惊讶、悲伤、闭眼；表情变化不能改变眼距、鼻梁和下颌结构。
服装表：正背面、外套敞开/闭合、配饰位置；左右侧口袋、胸针、手表必须有侧别。
验收：每张图对照P0锚点；比较脸部结构、体型、衣装、特征点；记录accepted/rejected/unknown及原因。生成模型做不到稳定多视角时减少复杂视角、使用实拍参考或在后期处理，不无限重试。
