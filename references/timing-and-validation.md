# 时长、对白与镜头时间轴
每段镜头从0.0开始，到目标时长T结束；区间采用左闭右开 `[start,end)`，连续镜头满足 `next.start == previous.end`。所有镜头时长总和必须等于T。
15秒例：镜1 0.0–4.0，镜2 4.0–9.0，镜3 9.0–15.0。末镜内部可留0.3–0.5秒反应或静默，不留下未分配时间。
对白预算：可说话秒数 = 镜头时长 - 起落动作 - 反应/停顿 - 预留。估算字数 = 可说话秒数 × 实测中文语速。初稿可按每秒3–4个汉字保守估算，最终以所选配音/视频模型测试为准；标点和停顿单独计时。
核验项：时长覆盖、单镜动作数量、角色ID存在、道具状态一致、对白归属、镜头间轴线、场景光位、平台参考图数量。
若总时长非整段倍数：优先允许尾段短于标准档（平台支持时），否则生成完整档位并在可剪区裁切；禁止裁掉台词与剧情关键动作。
